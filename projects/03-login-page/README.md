# 🔐 Login Page UI

A modern and responsive Login Page built using HTML and CSS. This project features a dual-panel layout with a welcome section and a login form, styled using gradients, shadows, and rounded corners.

## 📸 Preview

- Gradient background
- Split-screen design
- Welcome panel with logo
- Login form with username and password fields
- Remember Me checkbox
- Sign Up and Forgot Password links
- Hover effects on buttons

## 🚀 Features

✅ Modern UI Design  
✅ Flexbox Layout  
✅ Gradient Backgrounds  
✅ Rounded Corners  
✅ Box Shadow Effects  
✅ Login Form Components  
✅ Custom Styling with Pure CSS
