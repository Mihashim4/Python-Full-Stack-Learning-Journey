# 01 - Grade Calculator 📊

A simple Python program that takes a student's mark as input and prints the corresponding grade.

## 📝 Description

The program asks the user to enter their mark, then uses `if` / `elif` / `else` to assign a grade based on the score.

## 🏷️ Grading Scale

| Marks Range | Grade |
|-------------|-------|
| 95 – 100 | A+ (Excellent) |
| 80 – 94 | A |
| 65 – 79 | B |
| 45 – 64 | C |
| 35 – 44 | D |
| Below 35 | Failed |

## ▶️ How to Run

```bash
python Grade_calculator.py
```

Then enter your mark when prompted.

### Example

```
Enter your mark:    88
You got grade A
```

## 🧠 Concepts Practiced

- User input with `input()`
- Type conversion (`int()`)
- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
