# 01 - Product Card 🛒

A simple, single-file HTML product card showcase featuring four gaming laptops with prices, descriptions, and Amazon "View" + "Add to Cart" buttons.

## 📝 Description

A self-contained HTML page that uses pure inline CSS to lay out four product cards (Acer Nitro 5, ASUS ROG Strix G15, Lenovo Legion 5, MSI GF65 Thin) in a row against a dark background. Each card shows the laptop image, title, short description, price, an Amazon link, and an "Add to Cart" button.

## ✨ Features

- Pure HTML + inline CSS — no external dependencies
- Four product cards with hover effects on buttons
- Responsive flex layout
- Mix of remote (GitHub-hosted) and local product images
- Direct Amazon affiliate-style "View" links

## 🛠️ Tech Stack

- HTML5
- CSS3 (inline, no build step)

## ▶️ How to Run

Just open the file in any browser:

```bash
# Option 1: double-click
open "product card.html"

# Option 2: from terminal (Windows)
start "product card.html"
```

> Note: the file name has a space — quote it in shell commands.
