# Pages

These are the route-level components rendered by React Router.

| File | Route | Description |
|------|-------|-------------|
| `Home.jsx` | `/` | Hero banner + business intro + tyre partners |
| `Products.jsx` | `/products` | 16 auto parts categories with expandable details |
| `About.jsx` | `/about` | Company history and background |
| `Contact.jsx` | `/contact` | Contact details + send message form |

## Notes
- Products page uses `useState` to toggle "View Details" on each card
- Contact page uses Bootstrap grid (`col-md-5` + `col-md-7`) for two-column layout
