# src Folder

This folder contains all the React source code for the Hashim Auto Parts website.

## Structure

| File / Folder | Purpose |
|--------------|---------|
| `components/` | Reusable UI components (Navbar, Footer) |
| `pages/` | Route-level page components (Home, Products, About, Contact) |
| `App.jsx` | Main app component with React Router setup |
| `App.css` | Global styles and custom CSS |
| `index.js` | Application entry point |
| `main.jsx` | React 18 root render |
| `index.css` | Base CSS imports |
| `logo.svg` | React logo (default) |
| `reportWebVitals.js` | Performance metrics |
| `setupTests.js` | Test configuration |
