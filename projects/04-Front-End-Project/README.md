# HASHIM Auto Parts Website

A tribute website created in loving memory of my grandfather’s old auto parts shop in Marthandam.

---

## About the Project

**HASHIM Auto Parts & Old Motor Spare Parts** was a trusted shop that supplied new and old spare parts for cars, lorries, and autos.  

Although the physical shop no longer exists, this website keeps its memory alive.

---

## Features

- Clean and modern multi-page website
- Home page with introduction and product preview
- Detailed Products page with expandable lists
- About page telling the shop’s story
- Contact page with form and shop details
- Smooth fade-in animations
- Interactive “View Details” buttons
- Responsive design
- jQuery effects
